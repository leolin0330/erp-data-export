
# ERP Data Export Automation

### Python + Selenium ERP 自動化資料匯出工具

------------------------------------------------------------------------

# 專案介紹

此專案為一套 **ERP 系統自動化工具**，使用 **Python + Selenium** 開發，\
用來自動登入公司系統並批次匯出資料。

透過瀏覽器自動化技術，自動完成：

-   系統登入
-   進入交易資料模組
-   勾選資料
-   匯出 Excel
-   自動下載檔案
-   下載完成檢測
-   檔案重新命名
-   切換工廠資料


------------------------------------------------------------------------

# 自動化流程

    啟動瀏覽器
         ↓
    登入 ERP 系統
         ↓
    進入交易資料模組
         ↓
    設定每頁資料筆數
         ↓
    勾選全部資料
         ↓
    匯出 Excel
         ↓
    監控下載完成
         ↓
    重新命名檔案
         ↓
    切換工廠
         ↓
    再次下載

# 技術架構

  |技術    |         用途|
  |-----|-----|
  |Python        |   自動化程式|

  |Edge WebDriver  | 控制瀏覽器|
  |WebDriverWait  |  動態等待|
  |glob           |  下載監控|
